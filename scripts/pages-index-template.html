🦑 Krauken

Open-source fermentation chamber controller for a Raspberry Pi.

v{{VERSION}} Raspberry Pi OS Debian package

What this is

Krauken drives a fermentation chamber end to end: a control daemon and hardware supervisor, a web API, and a React frontend, all running as one service on a Raspberry Pi. It can talk to a BrewPi-compatible Arduino controller, Tilt hydrometers over Bluetooth LE, and the Krauken project's own custom PCB -- pick whichever hardware you actually have.

Early days -- v{{VERSION}}. This is a DIY project: the Krauken PCB isn't sold anywhere, so most of what you'll actually run today is the BrewPi/Tilt support. Expect rough edges.

Install

Adds this apt repository, then installs the package normally:

curl -fsSL {{PAGES_URL}}/krauken-archive-keyring.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/krauken-archive-keyring.gpg

echo "deb [signed-by=/usr/share/keyrings/krauken-archive-keyring.gpg] {{PAGES_URL}} stable main" \
  | sudo tee /etc/apt/sources.list.d/krauken.list

sudo apt update && sudo apt install krauken

Before you install

  • Target is Raspberry Pi OS (or any Debian-based distro) on a Pi -- armv6l, armhf, and arm64 are all supported.
  • The package ships as source, not a prebuilt binary: on first install, it creates a real Python virtualenv and compiles a small EEPROM utility natively on your Pi (using piwheels.org for prebuilt wheels of compiled dependencies). This needs network access and takes longer than a typical apt install.
  • If brewpi.service is already running on the box, the installer asks before stopping/disabling it -- it never deletes BrewPi's own files.

After you install

Check it's running:

systemctl status krauken-api krauken-daemon

By default the web API only listens on 127.0.0.1:8080 (localhost). To reach it from another device on your network, edit /etc/krauken/krauken.conf, set KRAUKEN_API_HOST=0.0.0.0, then sudo systemctl restart krauken-api and browse to http://<your-pi's-address>:8080.
